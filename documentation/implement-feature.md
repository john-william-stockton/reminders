# Implement Feature

## Steps
1. Grab first `Not yet implemented` feature from `./FEATURES.md`, create an implementation plan for the prompter to review. 
2. Only implement once permission is granted explicitly.
3. Prompt the user to manually verify the feature, and then ensure `./FEATURES.md` has been updated appropriately and commit and push changes only once explicitly granted permission.
4. If there are more features documented, prompt the user if you should stop now or go back to step 1. If no more features, suggest a new feature to be added (upon approval).
