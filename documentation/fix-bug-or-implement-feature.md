# Fix Bug / Implement Feature

## Steps
1. If there's an `Open` bug in `./STATUS.md`'s Bugs section, grab the first one and create an
   organized bug-fix plan for the prompter to review. Otherwise, grab the first `Not yet
   implemented` feature from the Features section and create an implementation plan instead.
   - If both lists are empty: analyze the code for evident and potential bugs, add them to the
     list (upon approval), and repeat this step. If there's truly nothing left even after that,
     suggest a new feature to be added (upon approval) and implement it (also upon approval).
2. Only implement the plan once permission is explicitly granted.
3. Prompt the user to manually verify the fix/feature, then ensure the corresponding section of
   `./STATUS.md` has been updated appropriately, and commit and push changes only once explicitly
   granted permission.
